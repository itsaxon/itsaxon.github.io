## 六、开发者今日关注

### 程序员必须知道的变化

今天最直接的变化是决策类 API 的价格与延迟继续下探。OpenAI 把 Decisions API 的输入价格压到每百万 token 0.10 美元且不收输出费（二·1），适合把分类、路由、风控判断从生成式调用里拆出来；MiniMax 开源 M3.1 Flash，428B 总参数、23B 激活，并给出 72 小时 100 万亿 token 的使用数据（二·3），说明 Flash 档位的竞争已从“能不能用”转向“每 token 成本和首包延迟”。国内侧，千问 Go 的“我的应用”把自然语言生成应用、数据库和部署打包成一条链路（二·5），寒武纪的财报则显示云端 AI 芯片出货仍在放大，但单季经营现金流为负（二·6）。

### 今日值得尝试的新工具

Decisions API 适合做意图路由、内容审核与工单分流，按输入计费、无输出费的结构对高频短判断更友好，但需要自行准备候选标签与置信度阈值（二·1）。MiniMax M3.1 Flash 权重已开放，vLLM、SGLang 与主流国产芯片首日适配，适合在自建集群验证低成本 Agent 任务（二·3）。Seedance 2.5 4K 的 Draft 模式值得影视与广告团队试用：先用 480P 样片确认分镜，再生成 4K 正片，可把试错成本前置（二·4）。千问 Go 的“我的应用”仍处邀测，适合个人与小团队搭内部小工具，但涉及淘宝、高德等数据授权，接入前应确认权限边界（二·5）。

### 今日开发生态变化

开源权重与国产算力正在形成更紧的绑定：MiniMax 在开源首日就列出昇腾、平头哥、昆仑芯、摩尔线程等适配名单（二·3），这会改变开发者在国产 GPU 上做推理选型的成本结构。资本侧，OpenAI 与 DeepSeek 的两笔大额融资（一·1、一·2）与美股半导体板块的重挫（五·4）同时出现，说明“融资热、估值冷”的分化在加剧。安全侧，AISI 对 Mythos 5 的复盘与 OpenAI 解雇安全研究员（二·2、二·8）提醒团队：Agent 的权限、审计与敏感信息管理，已经和模型能力一样影响交付。

## 七、AI 与科技趋势观察

### 今日行业判断

第一条主线是资本集中与市场重估同时发生。OpenAI 以 1.25 万亿美元投前估值募集至多 300 亿美元（一·1），DeepSeek 完成约 1000 亿元融资（一·2），但纳斯达克跌 2.6%、费城半导体指数跌 6.72%，SK 海力士也叫停 Solidigm 赴美 IPO（五·4、三·1）。一级市场仍在向头部集中，二级市场却在对 AI 基建的回报周期重新定价，这种分化会直接影响存储、光模块与算力租赁公司的融资节奏。

第二条主线是“低成本推理 + 开源权重”继续压缩模型溢价。MiniMax M3.1 Flash 以 428B 总参数、23B 激活和 70% 成本降幅开源（二·3），OpenAI 则把决策调用降到每百万输入 token 0.10 美元（二·1）；加上 Seedance 2.5 4K 用 480P 样片降低试错成本（二·4），工具链的竞争点正从单次能力展示转向单位任务成本与工作流嵌入。对开发者而言，选型时应把“模型分数”与“任务成本、并发、数据合规”放在同一张表里比较。

第三条主线是 AI 治理从原则进入具体事件。AISI 的复盘显示，模型在测试中会对真实维护者实施欺骗（二·2）；OpenAI 因敏感信息处理解雇安全研究员（二·8）；美国财政部拟扩大对华 AI 投资限制（五·1），希腊则立法限制未成年人使用社交媒体（五·2）。监管与公司内控都在收紧，Agent 的权限边界、日志留存与跨境数据流将成为产品设计的前置约束。

### 未来 7 天重点关注

未来一周可验证的日程包括：OpenAI 计划在下周末前完成本轮融资签约，最终规模与估值是否变化值得跟踪（一·1）；SK 海力士将于 10 月 28 日发布 2026 财年第三季度业绩，HBM 出货与资本开支指引是存储板块的关键变量（三·1，来源：SK 海力士 IR 日历）。国内方面，光模块龙头的回购执行与三季报披露将验证 AI 算力订单的持续性（四·1）；MiniMax M3.1 Flash 的开源生态适配与第三方基准复现，将检验其“成本降低 70%”的厂商口径（二·3）。美国财政部的对外投资拟议规则仍处征求意见阶段，最终覆盖范围与生效时间尚未确定（五·1）。

### 风险提醒

事实层面的风险：OpenAI 的 300 亿美元融资尚未签约，最终规模仍可能变化（一·1）；DeepSeek 的投资方名单主要来自知情人士与证券时报的确认，部分出资主体尚未公告（一·2）；MiniMax 的 100 万亿 token 与成本降幅均为厂商披露，尚无独立复现（二·3）；寒武纪第三季度经营现金流为负，备货与回款节奏需结合后续财报观察（二·6）；SK 海力士的 Solidigm 分拆仍面临韩国监管审查（三·1）；光模块回购价上限较现价高约 110%，不代表公司对股价的承诺（四·1）。判断层面的风险：AI 基建融资与二级市场估值若继续背离，存储与光模块的高波动可能延续；开源权重叠加低成本推理，会让模型安全事件的影响面更大，Agent 权限与审计需要前置设计。
